## Deskripsi Program

1. **`tugas1_bmi.py`**: Program untuk menghitung *Body Mass Index* (BMI) berdasarkan input berat badan (kg) dan tinggi badan (m) serta mengelompokkannya ke dalam status berat badan.
2. **`tugas2_nilai_mahasiswa.py`**: Program pengelolaan data mahasiswa menggunakan `list` dan `dictionary` untuk menghitung nilai akhir, menentukan grade (A-E), menampilkan tabel rapi, serta mencari nilai tertinggi & terendah.
3. **`math_operations.py`**: Modul kustom berisi fungsi-fungsi geometri (persegi, persegi panjang, lingkaran) dan fungsi konversi suhu (Celsius ke Fahrenheit/Kelvin).
4. **`main.py`**: Skrip utama untuk menguji seluruh fungsi modul `math_operations.py` dengan menerapkan 2 cara `import` berbeda.
